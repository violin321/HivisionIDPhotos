# Phase 4 Web v2 deployment prep

Target external host: `https://idphoto-ai.violinai.qzz.io`.

Do **not** point this stack at `idphoto.violinai.qzz.io`; that hostname is reserved for the existing Gradio site.

## Services

- FastAPI adapter: `deploy_api:app`
  - default local port: `8000`
  - health: `GET /api/health`
  - static generated files: `/runtime/uploads/*`, `/runtime/results/*`
- Web v2: `web/` Next.js app
  - default local port: `3000`
  - API base configured by `NEXT_PUBLIC_API_BASE_URL`

## Local smoke

```bash
.venv/bin/python -m py_compile deploy_api.py
.venv/bin/python -m uvicorn deploy_api:app --host 127.0.0.1 --port 8000
API_BASE_URL=http://127.0.0.1:8000 .venv/bin/python scripts/e2e_phase4_api.py

cd web
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000 npm run build
NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000 npm run dev -- --port 3000
```

One-command local API check:

```bash
./scripts/run_phase4_local.sh
```

## Production environment

Suggested values for the target deployment:

```bash
API_HOST=127.0.0.1
API_PORT=8000
WEB_PORT=3000
NEXT_PUBLIC_API_BASE_URL=https://idphoto-ai.violinai.qzz.io
```

If a reverse proxy serves both apps under the same origin, route:

- `/api/*` -> FastAPI `127.0.0.1:8000`
- `/runtime/*` -> FastAPI `127.0.0.1:8000`
- everything else -> Next.js `127.0.0.1:3000`
